# Decisions

Record architectural decisions with rationale. Newest at the bottom.

- 2026-09-25 (r003): Base framework vendored (copied, not referenced) from mikesdatawork/gtk-python-dashboard-starter — doctrine rule 1. GTK3/PyGObject, run via system python3.
- 2026-09-25 (r003): Phosphor icons (MIT) as the icon system. Master library machine-wide at ~/projects/assets/icons; project subset resources/icons/{regular,fill} with suffix-stripped names so one key works across weights. No `regex` icon exists in Phosphor → `brackets-curly`; no `arrows-sort` → `sort-ascending`/`sort-descending`.
- 2026-09-25 (r003): v1 search engine is non-indexed streaming scan (os.scandir, one worker per mountpoint, st_dev containment, Event-based pause/stop). Indexing deferred (non-goal v1).
- 2026-09-25 (r004): Operator picked UI direction: Mockup A — Dashboard Classic, plus a collapsible right preview pane (folds to a 36px icon rail). Reference: docs/mockups/mockup-a2-preview.html; verified in both states.
- 2026-09-25 (r005): Remote = private MensuraMedia/linfilesearch; design phase (b6bb7df) pushed.
- 2026-09-25 (r005): Wildcard mode uses fnmatch full-match semantics (same as find -name): `report*.odt` does NOT match `q3-financial-report.odt`; users write `*report*.odt` for match-anywhere. Invalid regex compiles to a never-matching predicate instead of raising.
- 2026-09-25 (r005): Mount classification: gvfs FUSE searchable; other FUSE (AppImage/portal mounts) skipped; /boot/efi excluded by prefix rule. Verified live: searchable = /, /home, /mnt/data.
- 2026-09-25 (r006): Operator rule — main-page buttons never exceed sidebar nav button dimensions (28×130). Caps in config_layout MAIN_BUTTON_*; enforced by tests/test_button_caps.py. GTK3 note: the starter's `* { font-size: 11pt }` matches child labels directly and overrides parent-class font inheritance — button labels need explicit `.class label {}` rules. Fixed: style.css was never loaded at startup; main.py now calls ThemeManager().load_css.
- 2026-09-25 (r007): History/Saved model — every search run is recorded (query, mode, case, scope, final counts) to ~/.config/linfilesearch/history.json (cap 100); bookmark copies to saved-searches.json deduped by signature. Re-run path: AppController navigates to Search, syncs sidebar active state, prepopulates criteria, starts search immediately. Single-click semantics on sheets via TreeView button-press-event with column hit-testing (bookmark/trash are pixbuf columns). History/Saved refresh is synchronous on_change (all mutations are main-thread; GLib.idle_add never fires in tests).
- 2026-09-25 (r008): Button sizing — preferred/natural height is NOT predictive of rendered size (offscreen allocation measurement also unreliable); ground truth is pixel measurement on a live screenshot. Every main-page button is pinned to MAIN_BUTTON_TARGET_HEIGHT (24px) via height-request with 12px icons + 8pt labels + minimal CSS padding; rendered result verified 24px vs sidebar ~40px. License: CC BY-NC 4.0, author MensuraMedia, LICENSE carries author header + canonical legal code; README documents terms (commercial use requires author permission).
- 2026-09-25 (r010): App icon = dark rounded tile (#2d2d2d) + accent-blue Phosphor fill magnifier, generated by s013 (13 sizes, resources/images/app-icon + logo). Installer s014 (user-level: hicolor + ~/.local/bin/linfilesearch + .desktop StartupWMClass=linfilesearch, --uninstall). Tray: AyatanaAppIndicator3 with Gtk.StatusIcon fallback; window close hides to tray; WM_CLASS instance 'linfilesearch' via GLib.set_prgname. Search row reads as one segmented control (joined mode group, borderless pause/stop).
- 2026-09-25 (r011): Spreadsheet behavior: TreeViewColumn double-click edge auto-fit via Pango measurement (treeview_utils; text model index registered per column with set_text_index; caps 40-400px). Previews: images → scaled pixbuf; PDF → pdftoppm first page; odt/docx/xlsx → text extracted from zip XML (utils/preview.py). Search row uniform at 30px (SEARCH_ROW_HEIGHT); MAIN_BUTTON_MAX_HEIGHT corrected to 36 = rendered sidebar height (nominal 28 never rendered). Sidebar logo transparent (s013_a; tiled icon kept only for taskbar/tray). GDK3 gotcha: Gdk.BUTTON_PRIMARY_BUTTON is not introspectable — compare event.button == 1; and synthesized-event tests must pass the unwrapped event.button member, not the Event union.
